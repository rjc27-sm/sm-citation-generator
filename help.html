Quick lookup

Why didn't the URL lookup fill in the page title?

The tool tries 3 methods to retrieve the title:

  1. It fetches the raw HTML and looks for embedded metadata (Open Graph tags), which most modern sites include for social sharing.
  2. If that finds nothing, it uses a second service that fully renders the page including JavaScript.
  3. If both fetches fail, it infers a title from the words in the URL and flags it for you to verify.

Even so, some pages can't be retrieved. Common reasons include:

  • the site uses a security service such as Cloudflare, which blocks automated requests before they reach the page content
  • the content is behind a paywall or login.

If the title field is still blank or incorrect, copy the title from the page itself and paste it in.

Why doesn't the URL lookup fill in the publication year?

Web pages have no standard machine-readable field for publication year. Dates appear in many different formats and locations, and attempting to extract them automatically would produce too many errors.

Check the page itself for a publication or last-updated date and enter it in the Year field.

Why didn't the URL lookup identify the organisation?

The tool matches .gov.au domain names against a built-in list of approximately 160 Australian Government bodies. Organisation pre-filling will not work if:

  • the agency's domain isn't in the list
  • the URL belongs to a state/territory or non-government website.

Switch to the Organisation mode in the author field and enter the abbreviation and full name manually.

My DOI wasn't found – what should I do?

The tool looks up DOIs via CrossRef. If the item isn't indexed in CrossRef (common for some government publications and preprints), the lookup will fail.

Use the Manual entry tab and enter the details by hand. You can still include the DOI in the DOI field – it will be hyperlinked in the citation.

My ISBN wasn't found – what should I do?

The tool looks up ISBNs via Open Library, then Google Books as a fallback. Government reports, specialist publications, and older books are often not indexed in either database.

Use the Manual entry tab instead.

The Quick Lookup selected the wrong source type – can I change it?

Yes. Click Edit details under the generated citation, then select a different source type using the buttons at the top of the form. Any pre-filled data will carry across to fields with matching names.

Manual entry

How do I enter author names?

Click + Add author and fill in the given name(s) and family name in the separate fields. The tool formats the name to Style Manual conventions automatically (family name + initials, no full stops).

For a long author list, use Paste author list. Paste names separated by commas, semicolons, ampersands, or line breaks, in any order (e.g. 'Smith J, Jones A' or 'Jane Smith; Alex Jones'). The tool will strip credentials (PhD, MD and so on) and affiliation numbers.

How do I cite a source where the author is an organisation?

Select Organisation in the Author field toggle (available for Webpage, Govt report, Data set and Media release types). Enter the abbreviation and the full name in the 2 fields.

If the organisation has no abbreviation, leave the abbreviation field blank and enter the full name only.

What is 'sentence case' and should I use it?

The Style Manual requires titles in sentence case: only the first word and proper nouns are capitalised. If the title you've copied is in title case (Every Word Capitalised), click Convert to sentence case to apply the conversion automatically.

The tool preserves ALL-CAPS acronyms (such as ABS, UNESCO, NDIS). Always review the result. Proper nouns such as place names and people's names won't be re-capitalised automatically and you may need to correct them manually.

The citation shows 'n.d.' instead of a year – why?

'n.d.' (no date) is the Style Manual convention when a publication year is not available. It appears when the Year field is left blank.

If the source has a year, enter it in the Year field and regenerate the citation.

How do I enter a date for a news article or media release?

These source types use a full publication date rather than just a year. Enter it in any of these formats – the tool will convert it automatically when you leave the field:

  • 4 March 2025
  • 4/3/2025 or 4/3/25
  • March 4, 2025

Copying and using citations

What is the difference between 'Copy plain text' and 'Copy with formatting'?

Copy with formatting copies the citation with italics and hyperlink intact, so it pastes correctly into rich-text environments such as Word and Google Docs.

Copy plain text strips all formatting. Use this for pasting into systems that don't support rich text.

How do I copy an in-text citation?

Below the reference list entry, you can see 2 in-text citation options, one with the author outside the parentheses and one with the author inside. Click the format you need to copy it.

How do I start a new citation?

Refresh the page in your browser (press F5, or Ctrl+R on Windows, or Cmd+R on Mac). This clears all fields and returns the tool to its starting state.

The citation doesn't look right – what should I do?

The tool pre-fills what it can find, but you should always check citations before use. Click Edit details to go back to the form and correct any fields, then regenerate.

For complex or unusual sources, the Manual entry tab gives you full control over every field.

If you think the tool has a bug, use the feedback link at the bottom of the main page.

This tool generates citations following the Australian Government Style Manual author–date system.

Always check generated citations for accuracy, especially for complex sources.
